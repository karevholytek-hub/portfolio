# Галерея карточек товаров

Публичный раздел: `/portfolio/marketplace/`. Отдельный локальный редактор: `/portfolio/marketplace/?edit=1`. На основном сайте нет перехода сюда, в галерее нет перехода к основному сайту. `noindex,nofollow` — просьба поисковикам не индексировать; GitHub Pages не обеспечивает приватность и не блокирует ручной ввод адресов.

## Публикация
1. Откройте редактор, создайте карточку, добавьте 1–10 изображений/видео и расположите их в нужном порядке. Первый материал — обложка. Черновики с исходными файлами сохраняются в IndexedDB только текущего браузера.
2. Нажмите «Скачать ZIP для публикации». Распакуйте архив и загрузите `catalog.json` и папку `media` в `marketplace/` репозитория. Для больших видео используйте подходящий хостинг; браузерный загрузчик GitHub ограничивает размер одного файла 25 МиБ, обычный GitHub Git — 100 МиБ. Не публикуйте приватные материалы в публичный репозиторий.
3. После развёртывания GitHub Pages каталог будет одинаковым у всех посетителей. Локальный черновик не меняет опубликованный каталог.

Можно также редактировать `catalog.json` непосредственно: массив объектов `{id,title,desc,media:[{kind:'image'|'video',name,src}]}`. Уникальный `id`, до 10 медиа на карточку; `src` — относительный путь `media/...` либо HTTPS-ссылка. Без обрезки пропорций. Изображения JPG/JPEG, PNG, WebP, AVIF, GIF, BMP; видео MP4, WebM, MOV, M4V, OGV в зависимости от кодека и браузера. Для совместимости рекомендуются MP4 (H.264/AAC) или WebM. HEIC/TIFF не поддерживаются.

`legacy-catalog.json` сохраняет 5 прежних внешних ссылок на худи из `archive/pre-luminescence-2026-11-18.html`. Их доступность не подтверждена; они не включены в публичный каталог. При восстановлении исходников добавьте карточку в `catalog.json` с рабочими URL.
