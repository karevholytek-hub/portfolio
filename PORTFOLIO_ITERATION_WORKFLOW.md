# KAREV — Prompt Iteration Engine для предметного дизайна
Версия: 1.0 (2026-11-19). Основа: [оригинальный навык Prompt Iteration Engine, PR #9](https://github.com/karevholytek-hub/ai-shared-knowledge/pull/9), [ювелирные lessons](https://github.com/karevholytek-hub/ai-shared-knowledge/blob/feat/prompt-iteration-jewelry-qa-20261119/skills/jewelry-design-qa/lessons.md).

## Что сохраняем неизменным
Базовый brief v0 (носитель, размер, категория, бренд, реальный продукт, требования, запреты), подтверждённые факты, удачный ракурс/форма/свет/шрифт/цвет **конкретно по текущей версии**. Никогда не превращать удачный предмет в коллаж или постер, если задача другая. Без упоминаний внутренних инструментов в публичном результате.

## Форма промежуточного отчёта на каждую работу
- **OBJECT:** один конкретный носитель, размер, предмет.
- **BRIEF MUST:** обязательные свойства из исходного задания (не переписывать из последнего рендера).
- **BEST VERSION:** лучший сохранённый артефакт, не обязательно последний.
- **IDEA SCORE:** 0–10. **EXECUTION SCORE:** 0–100 (взвешенные 100 критериев). **POTENTIAL:** 0–10.
- **LOCK:** какие сильные детали зафиксировать дословно в следующем промпте.
- **FIX:** 1–3 приоритетных дефекта с местом, причиной, наблюдаемым результатом и критериями проверки.
- **AVOID:** какие конкретные уже виденные ошибки нельзя повторять. Указываем наблюдаемый дефект и чем его заменить.
- **ROOT CAUSE:** ошибка данных, промпта, модели, способа композитинга или скрининга; GEOMETRY/LAYOUT/STYLE/PHYSICS/FACT_HALLUCINATION/OUTPUT_FORMAT/NOVELTY/TOOL_FAILURE.
- **NEXT PROMPT:** MUST + LOCK + исправления FIX + AVOID + метод выполнения; никаких конфликтов с MUST.
- **VERIFY:** сравнение с предыдущей лучшей версией, артефакты и отсутствие регресса LOCK.
- **DECISION:** KEEP / REFINE / CHANGE_METHOD / PARK / USER_REVIEW; если критические блокеры — НЕ ПУБЛИКОВАТЬ, но идею можно сохранить.

## Как составлять обновлённый промпт
```text
[BASELINE MUST]
Изготовить/оформить ОДИН конкретный предмет [носитель], [объём/размер/ракурс].
Подтверждённые сведения, цель, аудитория, формат: ...

[LOCK — СОХРАНИТЬ БЕЗ ИЗМЕНЕНИЙ]
1. [точно описанная удачная часть и координаты/цвет/форма при наличии]
2. [конкретная удачная часть]
3. ...

[FIX — ПОДРОБНЫЕ ПРАВКИ]
1. Было: [дефект] / Причина: [почему] / Сделать: [действие] / Должно быть: [измеримый эффект]
2. ...

[AVOID — НЕ ПОВТОРЯТЬ]
1. [прошлая ошибка] → [позитивная альтернатива].
2. ...

[METHOD — ТЕХНИКА]
Какие части рисуем генератором, а какие строим вектором/точной версткой/3D.
Что необходимо проверить вручную и по исходным данным.

[QA]
Показать только предмет; проверить оригинальные MUST и LOCK, текст, геометрию,
факты, материалы, экспорт, формат, композицию, регресс относительно BEST VERSION.
```

## Особенности переноса уроков из украшений
- J-01: Слова «примерно» в геометрии заменять размерами, шаблоном или отношениями.
- J-02: Верные размеры не равны художественному качеству; нужна отдельная экспертная оценка.
- J-03: Локальная деформация портит соседей; проверять края, текст и швы после правки.
- J-04: Один предмет вместо коллажа с отчётом.
- J-05: Числа/логотипы/надписи строить точно, а не доверять их случайной генерации.
- J-06: Менять структуру/архитектуру для нового концепта, а не перекрашивать шаблон.
- J-07: Избыток декора не означает дорогой дизайн; сокращать визуальный шум.
- J-08: Один фронтальный ракурс не доказывает готовность к производству; нужны отдельные виды/развёртки.

## Сценарии оценки (только индивидуально)
**92 балла, идея 8/10, плохой вторичный шрифт:** KEEP / REFINE, заменяем только шрифт, сохраняем остальные удачные параметры.
**76 баллов, идея 9/10, испорчена форма тюбика:** KEEP IDEA / CHANGE_METHOD, оставляем концепцию, строим корректный 3D-шаблон тюбика, компонуем этикетку заново.
**94 балла, критический факт неверен:** BLOCK_PUBLICATION, исправляем факт и перепроверяем, не стирая сильный дизайн.
**45 баллов, идея 3/10:** PARK; лучше вложиться в другой концепт.
**Партия 20 работ:** 2 удачные — сохраняем эти 2, другие не влияют на решение по ним.

## Ограничения
Оригинальный runner — только для подключённых CLI генератора и проверяющего. Этот документ не означает, что здесь настроен фоновый генератор. Автоматические проверки не подтверждают художественную оценку или производственную пригодность. Все оценки должны сопровождаться реальным осмотром артефакта.
